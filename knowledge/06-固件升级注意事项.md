# 设备固件升级注意事项

## 升级前

1. 备份当前配置：`display current-configuration`（华为）或 `copy running-config startup-config`（思科）
2. 备份关键数据与日志
3. 确认设备型号与目标版本兼容性，查阅 Release Notes
4. 确认设备存储空间充足

## 升级中

- 保持电源稳定，避免中断（建议双电源 / UPS）
- 通过带外管理或 console 观察升级进度
- 升级过程中不要断电或重启

## 升级后

- 核对版本号与启动项
- 验证关键业务与路由协议正常
- 升级失败时需可回滚到旧版本

## 回滚

- 保留旧版本镜像与启动配置
- 回滚操作同样需走变更流程
