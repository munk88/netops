# 巡检常用命令

## 思科

- `show version` 版本与运行时间
- `show cpu` CPU 利用率
- `show memory` 内存
- `show interface summary` 接口汇总
- `show log` 日志
- `show ip route` 路由表

## 华为

- `display version` 版本
- `display cpu-usage` CPU 利用率
- `display memory-usage` 内存利用率
- `display interface brief` 接口状态汇总
- `display logbuffer` 日志缓冲
- `display ip routing-table` 路由表

## 巡检建议

- 重点关注接口状态异常（Down / Err-disable）与 CPU 持续高
- 对比基线，异常项进工单跟踪
